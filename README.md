# Cursor Clone

A recreation of the Cursor AI code editor landing page, built with HTML and CSS only.

## 📋 Sections Recreated

This clone recreates the following sections from the original Cursor website:

### 1. **Navigation Bar**

- Logo and branding
- Navigation links (Features, Enterprise, Pricing, Resources)
- Sign in and Download buttons

### 2. **Hero Section**

- Main headline text
- Primary call-to-action button (Download for Windows)
- Hero image display

### 3. **Social Proof Section**

- Trust statement
- Company logo cards (Stripe, OpenAI, Linear, Datadog, NVIDIA, Figma, Ramp, Adobe)

### 4. **Feature Cards** (Left-Right Layout)

- **Agent**: "Agent turns ideas into code"
- **Autocomplete**: "Magically accurate autocomplete"
- **Ecosystem**: "Everywhere software gets built"

### 5. **Testimonials Section**

- "The new way to build software" heading
- 6 testimonial cards featuring:
  - Diana Hu (Y Combinator)
  - shadcn (shadcn/ui Creator)
  - Andrej Karpathy (Eureka Labs)
  - Patrick Collison (Stripe)
  - ThePrimeagen
  - Greg Brockman (OpenAI)

### 6. **Product Description**

- "Stay on the frontier" heading
- 3 description cards highlighting:
  - Access to best models
  - Codebase understanding
  - Additional features

### 7. **Changelog Section**

- Recent version updates and features
- 4 changelog cards with dates and version numbers

### 8. **Call-to-Action (Secondary)**

- "Cursor is an applied team..." heading
- Join Us button
- CTA image

### 9. **Highlights Section**

- Recent highlights grid layout
- Blog post previews with dates and categories

### 10. **Final CTA Section**

- "Try Cursor now" heading

- 5 column layout with links:
  - Product

## 🛠️ Technologies Used

- **HTML5** - Semantic structure
- **CSS3** - Modern styling with Grid and Flexbox
- **Vite** - Development server and build tool

## 📦 Setup & Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```
